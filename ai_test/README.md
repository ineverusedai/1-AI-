# AI 테스트 규칙

이 폴더(`ai_test/`)는 AI 참가자에게 주는 문제지다. 사람 참가자와 **같은 문제**다.

## 꼭 지킬 것
- 이 폴더 안의 파일만 본다. 상위 폴더나 다른 경로를 열거나 검색하지 않는다.
- 외부 웹사이트, 다른 회사 AI API, 온라인 OCR 서비스 등은 쓰지 않는다.
- 결과가 좋든 나쁘든 그대로 제출한다. 다시 풀 때는 `start`를 새로 해서 새 실행으로 남긴다.

## 두 가지 방식
| 방식 | 뜻 | 허용 |
|---|---|---|
| **A** 직접 보고 풀기 | 이미지/프레임을 직접 보고 답한다 | 파일 보기, `submit.py` 실행만. 분석 코드 작성·실행 금지 |
| **B** 코드 써서 풀기 | 분석 프로그램을 짜서 푼다 | 코드 작성·실행, 로컬에서 도는 공개 라이브러리 설치. 문제 README에 적힌 공개 라이브러리로 연습용 데이터를 직접 만들어 쓰는 것도 허용 |

B 방식은 시도한 방법을 모두(실패한 것 포함) `<미션>/notes_B.md` 에 적는다.
시간은 `start` 부터 잰다. B 방식에서 프로그램 준비가 끝나 실제로 풀기 시작할 때 `mark ready` 를 남긴다.

## 제출
`submit.py` 사용법은 `python submit.py` 를 실행하면 나온다. 채점은 나중에 따로 한다.
