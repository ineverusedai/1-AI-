# 미션 1: 글자 캡차 (AI 테스트)

`images/q001.png` ~ `images/q200.png` 에 찌그러진 글자 이미지가 있다. 각 이미지의 글자를 그대로 적는 문제다.

- 글자 수: 5자
- 쓰이는 글자: 대문자 A-Z, 숫자 0-9. 소문자는 없다 (대소문자 구분 없이 채점).
- 문제 3개 중 1개꼴로 헷갈리는 글자가 하나 섞여 있다: 0(숫자 영) / O(대문자 오) / 1(숫자 일) / I(대문자 아이)
- 이미지는 Python `captcha` 라이브러리 0.7.1(lepture/captcha, `ImageCaptcha(width=280, height=90)`, 기본 글꼴)로 만들었다.

## 사람과 같은 규칙
60초 안에 10문제 연속 정답이면 성공. 틀리면 연속 카운트가 0이 된다.
문제는 반드시 **1번부터 번호 순서대로** 푼다. 틀렸다는 알림은 없다(채점은 나중에 따로 한다).

## 기록되는 것
1. 1~10번을 푸는 데 걸린 시간과 정답 수
2. 시작 후 60초 안에 맞힌 문제 수 (= "1분 동안 최대 몇 문제")
3. 위 규칙대로 했을 때 성공 여부

## 제출
`python ../submit.py m1 <A 또는 B> start` 로 시작 → 문제마다 `python ../submit.py m1 <A 또는 B> answer <번호> <답>`
→ 끝나면 `python ../submit.py m1 <A 또는 B> end`. 할 수 있는 만큼 계속 풀어도 된다(최대 200번).
