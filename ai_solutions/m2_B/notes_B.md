# 착시 캡차 전용 풀이 모델 — 작업 기록 (방식 B)

- 시작: 2026-11-24 08:45 UTC, 끝: 10:25 UTC (약 1시간 40분)
- 환경: CPU 4코어, GPU 없음. torch 2.15 / numpy / opencv / Pillow 만 사용. **pip 설치 없음.**
- 외부 자료: 시스템 글꼴 `/usr/share/fonts/truetype/wqy/wqy-zenhei.ttc` (템플릿 매칭용) 만 사용.

## 1. 자료 관찰
- 3,000장, 정답은 모두 **두 글자 단어**(136종, 단어당 약 22장). 선택지 4개 = 두 글자 단어 3개 + 배경 설명 1개
  ('꽃이 핀 풀밭' / '나무가 빽빽한 숲' / '나뭇잎이 쌓인 땅'). 배경 설명은 한 번도 정답이 아님.
- 3,000문제 중 2,920문제에서 단어 선택지 3개가 **첫 음절이 같음** (예: 시장/시계/시간) → 사실상 둘째 음절 구분이 핵심.
- 글자는 배경 위에 넓게 어둡게 깔린 "그림자". 회색조 → 작게 줄이기 → 가우시안 블러 → 큰 블러(배경)를 빼서 정규화하면
  사람 눈에도 또렷한 글자가 됨 (눈을 가늘게 뜨는 것과 같은 효과).

## 2. 검증 방식
- `labeled` 3,000장을 시드 12345로 섞어 **held-out 600장**(학습·튜닝에 전혀 사용 안 함, 마지막에 한 번만 평가),
  **val 300장**(방법 비교·튜닝용), **train 2,100장**으로 나눔. 분할은 `work/split.json`.

## 3. 시도한 방법과 결과

| # | 방법 | val 정답률 | 학습 시간 | 비고 |
|---|------|-----------|----------|------|
| A1 | 글꼴 템플릿 매칭 (120×75 전처리, 글자 높이 14~24px) | 74/300 (24.7%) | 없음 | **실패**: 템플릿이 실제 글자보다 작았음 |
| A2 | 같은 방법, 글자 높이 20~32px | 281/300 (93.7%) | 없음 | 학습 없이도 꽤 됨. 1문제 3ms |
| A3 | 템플릿 매칭, v3 전처리(160×100) 채널0, 높이 26~44px, 블러 1.5 | 286/300 (95.3%) | 없음 | 최종 solver의 대비책(모르는 음절용) |

| 최종 | B2 + B3 앙상블(로그확률 평균) + A3 대비책 | held-out **600/600 (100%)** | — | |

시도 중 버린 것: 전처리 변형 중 erosion(최솟값 필터)은 밝은 꽃이 오히려 커져 글자가 안 보여서 탈락(눈으로 확인 단계).

### CNN 세부
- 구조(`model.py`): conv3×3-BN-ReLU 2개씩 4단 (32→64→128→256채널, 사이에 maxpool 3번), 전역 max+avg 풀링, dropout 0.3,
  선형 머리 2개(첫 음절 / 둘째 음절, 음절 사전 110개 = train의 두 글자 선택지에 나온 음절).
- 학습: AdamW, OneCycle(최대 lr 3e-3), batch 64, label smoothing 0.05.
  증강: 무작위 이동(±12%), 확대축소(0.85~1.15), 회전(±4.6°), 세로 비율 변화, 가우시안 잡음.
- 점수: 선택지 단어 = log P(첫 음절) + log P(둘째 음절). 모든 단어가 공유하는 자리는 빼고 다른 자리만 비교.
  단어 사전 대신 음절 단위로 해서, 시험에 처음 보는 **음절 조합** 단어가 나와도 풀 수 있음.

### 일반화 대비 (시험 그림은 이 자료와 다름)
- 선택지에 학습 때 못 본 음절이 있으면: 아는 음절 후보 중 CNN이 확신(자리당 평균 확률 > 0.5)하면 그것을,
  아니면 글꼴 템플릿 매칭(A3)으로 고름.
- 점검(held-out 그림 사용, 튜닝 없음): 템플릿 매칭만 강제로 썼을 때 585/600 (97.5%).
  오답 선택지 하나를 처음 보는 단어 '퍼즐'로 바꾼 200문제: 하이브리드 후 200/200.

## 4. 최종 결과
- **held-out 600장: 600/600 = 100.0%** (`work/final_holdout.log`)
- solve() 시간 (held-out 600회, JPEG 바이트 → 답, CPU 4스레드): **평균 38.5 ms, 중앙값 37.1 ms, p99 63.2 ms, 최대 102.1 ms**
  - 단계별(중앙값): JPEG 디코드 5ms, 전처리 4ms, CNN 2개 19ms(4스레드) / 46ms(1스레드)
  - 처음에 1스레드로 재었을 때 평균 68 ms, p99 103 ms, 최대 130 ms → 4스레드로 바꿈.
  - import(모델 로드) 약 1.7초, 한 번만.
- 학습 시간 합계: 19.4 + 31.9 + 39.3 = **약 90.6분** (전처리 캐시 생성 약 1.6분 별도)
