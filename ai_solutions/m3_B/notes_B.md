# 미션 3 방식 B — 사인파 음성 캡차 전용 모델 학습 기록

작업 시간: 02:50 ~ 03:23 UTC (약 33분). 모든 작업은 이 폴더 안에서만 진행. torch 스레드 2개(`torch.set_num_threads(2)`, `OMP_NUM_THREADS=2`).

## 0. 데이터 분할 (어떤 분석·학습보다 먼저)
- `labeled/labels.json` 의 2,000문제 디렉터리 이름을 정렬 → `random.Random(20261125).shuffle` → 앞 400개 = **떼어 둔 검증(held-out)**, 나머지 1,600개 = 학습용.
- 분할은 `work/split.json` 에 저장. 정답 분포(전체): 1:515, 2:506, 3:466, 4:513.
- held-out 400개는 학습·튜닝·모델 선택에 쓰지 않았고, 최종 모델을 고정한 뒤 **한 번만** 평가했다.
- 모델 선택/에폭 결정용으로는 학습용 1,600개 안에서 다시 320개를 "내부 검증(inner-val)"으로 떼어 썼다(seed 1).

## 1. 데이터 관찰 (학습용만)
- 22,050 Hz, 16bit 모노. ref(깨끗한 음성) 길이는 제각각, 보기 4개는 한 문제 안에서 길이가 같게 패딩되어 있고 앞쪽 무음 길이(시작 위치)가 무작위.
- 보기 스펙트럼은 3~4개의 사인파(포먼트 추적) 형태. 진폭 최대값은 모두 26213으로 정규화.
- → 앞뒤 무음 자르기(-40 dB) + 시간 정렬(DTW)이 핵심이라고 판단.

## 2. 특징
- `feats.py`: 1024점 Hann STFT, hop 220(≈10 ms), 64밴드 mel(60–7000 Hz) 로그 에너지, 최대값-12(≈52 dB) 바닥, 앞뒤 무음 트림. 파일당 약 17 ms.
- 2,000문제 × 5파일 특징 추출 169초 (학습 시간과 별도).

## 3. 시도한 방법과 결과

### 방법 0 (학습 없음, 진단용 기준선) — 로그 mel + 코사인 거리 + DTW, 최소 거리 선택
- DTW: 기울기 1/2~2 제약(스텝 (1,1),(1,2),(2,1)), 경로 길이로 정규화.
- 학습용 1,600개에서 프레임 정규화 방식별 정답률:
  - 정규화 없음: 1535/1600 (95.9%)
  - 발화 평균 빼기(CMN): 1599/1600 (99.9%)
  - 프레임 평균 빼기: 1367/1600 (85.4%) ← 실패(스펙트럼 기울기 정보가 사라짐)
  - CMN+프레임 평균 둘 다: 1600/1600
- 이 기준선은 학습 기반이 아니므로 최종 해법으로 쓰지 않음(아래 학습 모델의 비교 대상).

### 방법 1 — DTW 거리 위의 학습된 점수기(조건부 로짓, 4지선다 softmax)
- 특징: 위 4가지 DTW 비용 + log(보기길이/ref길이), 그리고 각 값의 문제 내 평균 차감값(총 10차원). 가중치는 교차엔트로피+L2로 LBFGS 학습.
- 학습용 1,600개 5-겹 교차검증: 10차원 1600/1600, (CMN+둘다) 2개만 1600/1600, (없음+프레임+길이) 1537/1600 (96.1%).
- 학습 시간: 최종 적합 0.02초 (5-겹 CV 전체 11.8초).

### 방법 2 — 비대칭 샴(siamese) 프레임 거리 학습 + DTW  ← **최종 채택**
- `model.py`: ref용 인코더와 사인파용 인코더를 따로 둠(각각 1D Conv 64→128→128→48 + 선형 skip, 프레임별 단위벡터). 거리 = 1 − 코사인.
- 문제마다 보기 4개 각각에 대해 학습된 거리행렬로 DTW 최적 경로를 numpy로 구하고, 그 경로 위 비용 합(DTW의 부분기울기)을 torch로 미분 → 4지선다 softmax 교차엔트로피(학습 가능한 온도). Adam lr 1e-3, 배치 16문제.
- 내부 검증(학습 1,280 / 내부검증 320):
  - 초기화 직후(학습 전): 153/320 (47.8%)
  - 에폭 0: 320/320 (최소 여유 0.0237) … 에폭 7: 320/320 (최소 여유 0.0323, 계속 증가)
  - 학습 시간 8에폭 331.5초.
- 에폭 1부터 포화 → 에폭 수 4로 고정(held-out 보지 않고 결정), 학습용 1,600개 전체로 재학습: **학습 시간 390.5초**(다른 무거운 작업과 CPU를 나눠 써서 에폭당 약 95초).
- 선택 이유: 방법 1·3과 내부 검증 정답률은 같지만(모두 100%), 정답과 오답 사이 여유가 에폭마다 꾸준히 커지고, DTW의 시간 정렬 제약을 유지하면서 거리 자체를 데이터로 학습하는 "이 캡차 전용 모델"이라서.

### 방법 3 — DTW 없는 샴 신경망 (비교용)
- 같은 인코더 구조, 정렬 방법만 다름. 각 4에폭, 내부 검증 320개 기준:
  - (a) 평균 풀링 발화 임베딩 + 코사인 (정렬 없음): 274 → 316 → 318 → 320/320, 손실이 출렁여 불안정(마지막 에폭 손실 0.128). 학습 59.6초.
  - (b) 소프트 MaxSim(양방향 logsumexp, 단조성 제약 없음): 319 → 320 → 320 → 320/320. 학습 68.0초.
- 결과는 좋지만 (a)는 불안정, (b)는 시간 순서 제약이 없어 비슷한 음소 구성의 문장에 약할 것이라 판단해 채택하지 않음.

## 4. 최종 결과 (held-out 400개, 모델 고정 후 1회 평가)
- 최종 해법: 방법 2 (`solver.py` + `models/metric.pt`, 보조 모듈 `feats.py`, `dtw.py`, `model.py`).
- **held-out 정답률: 400/400 = 100.0%** (`work/heldout_eval.log`)
- **solve() 시간** (파일 바이트 → 답, 특징 추출 포함, 2스레드, 다른 작업과 CPU 공유 중 load avg ≈10): 평균 87 ms, 중앙값 56 ms, 최대 443 ms → 1초 이하.
- import(모델 로드) 1.7초, 1회만.
- 참고(최종 모델 고정 **이후** 기록용으로만 계산, 선택에 사용 안 함): 방법 1 로짓 점수기의 held-out 400/400.

- 순수 학습 시간: 최종 모델 390.5초(6.5분). 실험 포함 전체 학습 합계 ≈ 331.5 + 390.5 + 59.6 + 68.0 + 11.8 ≈ 861초(약 14분).
