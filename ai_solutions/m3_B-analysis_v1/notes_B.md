## 0. 데이터 관찰
- 모두 22050 Hz, 16bit mono. 문장 길이 약 1.3~2.7초. 24문제.
- 모든 파일의 md5 가 서로 다름(완전 동일 파일 재사용 없음).
- **메타데이터 관찰(사용하지 않음)**: ref 의 샘플 수와 정확히 같거나 1샘플 차이 나는 보기가 문제마다 하나씩 있다.
  이는 생성 과정의 흔적일 뿐 사람이 들을 수 있는 단서가 아니므로 **solver 에는 쓰지 않았다**. 다만 사후 비교해 보니
  아래 내용 기반 선택과 24문제 모두 같은 보기를 가리켰다 (독립적인 교차 확인 정도로만 기록).
- 사인파 보기의 스펙트럼: 프레임마다 3~4개의 사인 성분(약 300~3500 Hz, 포먼트 궤적을 따라 빠르게 움직임).

## 1. 시도한 방법과 결과

마진 = (1등 점수 − 2등 점수) / (4개 점수의 표준편차). 이론상 최대 4/√3 ≈ 2.31 (1등만 튀고 나머지 셋이 같을 때). 1 이상이면 꽤 분명한 분리.

| 방법 | 내용 | 24문제 선택 | 평균 마진 | 최소 마진(문제) |
|---|---|---|---|---|
| A | log-mel(40밴드, 100~5000Hz, 10ms) 밴드별 평균 제거 → 코사인 거리 DTW | 213332244111342331111342 | 1.63 | 0.78 (q10) |
| A2 | 같은 log-mel, DTW 없이 ±150ms 지연 탐색 후 전체 피어슨 상관 | 213332244111342331111342 | 1.56 | 0.66 (q14) |
| B | log RMS 엔벨로프(10ms), ±200ms 지연 탐색 최대 상관 | 213332244111342331111342 | 1.38 | 0.52 (q19) |
| C | ref: LPC(12차, 11kHz) 근으로 포먼트 F1~F3 / 보기: 스펙트럼 피크 상위 3개 → Bark 축 가우시안 "포먼트 이미지" → 코사인 DTW | 213332**1**44111342331111343 | 1.00 | 0.01 (q10) |

관찰
- A, A2, B 세 방법은 **24문제 모두 같은 보기**를 골랐다. 서로 성격이 다른 특징(스펙트럼 모양 vs 시간 엔벨로프,
  DTW vs 고정 정렬)이 일치하므로 신뢰도가 높다고 판단.
- B 에서 선택된 보기의 엔벨로프 상관은 0.86~0.94, 그리고 **모든 선택 보기의 최적 지연이 0프레임**이었다
  (오답 보기는 지연이 제각각, 상관 0.17~0.79 대부분). q19 의 opt2(0.88, 지연 4)만 리듬이 비슷한 방해 보기였고,
  A/A2 에서는 확실히 갈렸다(A 0.265 vs 0.310, A2 0.50 vs 0.42).
- A2 에서 선택 보기의 상관은 0.49~0.54 로 일정, 오답 최댓값은 0.46(q13 opt2) 정도.
- C(포먼트 추적)는 LPC 포먼트 추정 오류와 사인 피크 개수 불일치 때문에 가장 약했다. q07(1 선택), q24(3 선택)에서
  다른 방법과 달랐고 마진도 매우 작아(q10 0.01, q24 0.22) 신뢰하기 어려워 **최종에서 제외**.

## 2. 최종 방법 (solver.py)
- 입력 bytes → 22050Hz mono 로 변환(다른 표본율이면 resample), 최대값 정규화.
- A(−DTW 거리), A2(상관), B(상관) 세 점수를 각각 4개 보기 안에서 z-score 정규화 → 합산 → 최댓값 보기.
- 길이/샘플 수/파일 메타데이터는 사용하지 않음. 음성인식 모델 없음, 순수 numpy/scipy.
- 실행 시간: 문제당 0.10~0.57초, 평균 0.37초 (CPU).
