# AI 시점(POV) 연출 영상 — 장면 흐름 (대본용)

공통: 1920×1200(16:10) 60fps, 자막 없음. 화면 속 숫자·그림은 전부 실제 계산·실제 학습 기록이다.
문제는 시험 문제가 아니라 같은 방식으로 새로 만든 것(시험 문제 노출 방지). 오른쪽 위 빨간 숫자 = '직접 보고 풀기(A)' 실제 결과.

---

## M1 글자 캡차 (m1_pov.mp4, 26초)
1. **0–5초 연습 자료 공장**: 찌그러진 캡차가 쏟아지고 카운터가 300,000까지. 공개 라이브러리로 AI가 직접 만든 학습 자료(시험과 다른 시드).
2. **5–12초 읽는 법**: 캡차 아래 'CTC' 판에 36칸을 훑으며 글자 다섯 개(06UB9)가 하나씩 찍힘 → AI는 글자 위치를 따로 배우지 않고 왼쪽부터 순서대로 읽는다.
   오른쪽에 학습 단계별 판독: 에폭 0·1은 맞고, **에폭 4는 첫 글자 숫자 0을 영문 O로 틀림(빨강)**, 최종은 맞음. 옆 숫자는 각 단계 정답률(92.37% → 99.25%).
3. **12–17초 마지막 난관 0과 O**: 남은 오류 75개 중 67개가 0↔O. 그 글자만 원본 해상도로 잘라 '0/O 전문 판정기'가 다시 봄 → DIGIT 0 확률 1.00. 정답률 99.25% → 99.72%.
4. **17–21초 학습 곡선**: 에폭별 정답률 그래프, 학습 시간 카운터 3:16:00, 자료 30만 장·CPU 4코어.
5. **21–26초 실전 속도**: 새 캡차 200개를 연달아 풀며 초록(정답)/빨강(오답) 표시 → 198/200, 약 2.2초.
- 한 줄 요약: "AI는 30만 장을 보고 3시간 16분 만에, 사람 눈으로도 헷갈리는 0과 O까지 구별하게 됐다."

## M2 착시 캡차 (m2_pov.mp4, 26초)
1. **0–5초 입력**: 나뭇잎 그림을 십자선이 훑지만 'TEXT: ?' — 범용 AI가 원본만 보면 대부분 찍음(9/20). 오른쪽에 선택지 4개(나뭇잎이 쌓인 땅/노트/노래/노인).
2. **5–12초 눈 가늘게 뜨기**: 회색 → 작게 줄이기 → 흐리게 → 큰 얼룩 빼기 → 작은 점 지우기, 다섯 단계를 거치자 숨은 글자 '노트'가 하늘색으로 떠오름 (AI 전용 봇의 실제 전처리).
3. **12–16초 정답 달린 3,000장**: 학습 자료가 쌓이며 통계가 뜸 — '장면 설명이 정답인 경우 0/3,000' → 선택지 A에 빨간 줄(후보에서 제외). '첫 글자가 같은 문제 2,920/3,000'.
4. **16–21초 음절 읽기**: 두 개의 머리가 첫 음절(노)·둘째 음절(트) 확률을 막대로 → 선택지 점수 노트 −0.06, 노래 −8.02, 노인 −6.20 → 정답 '노트' 노란색.
5. **21–26초 학습 곡선**: 첫 모델(회색)과 개선 모델(하늘색, 해상도↑+점 지우기) 정답률 → 떼어 둔 600/600, 시험 200/200, 학습 1:31:00.
- 한 줄 요약: "AI는 '눈을 가늘게 뜨는' 방법과 '장면 설명은 늘 함정'이라는 규칙을 자료에서 스스로 찾았다."

## M3 소리 착시 캡차 (m3_pov.mp4, 27초, 소리 있음)
1. **0–9초 듣기(소리 재생)**: 깨끗한 원본 목소리의 소리 그림(흰색) → 사인파 소리 4개(하늘색 가는 줄 3~4개)가 차례로 재생되며 하나씩 켜짐. 사인파는 원본 1.3초씩만 들려줌. 'ZERO-SHOT N/A' = 직접 보고 풀기는 소리를 못 들어 제외.
2. **9–16초 시간 맞추기(DTW)**: 원본×각 소리의 비교 지도 4개에 노란 정렬 경로가 그려짐 → 오른쪽 비용 막대, 가장 낮은 '소리 3'(0.072)이 정답으로 강조. 말 속도가 달라도 시간축을 늘였다 줄여 맞춰 비교하는 방법.
3. **16–21초 학습 전 vs 후**: 같은 비교를 학습 전(무작위) 인코더로 하면 **소리 2를 골라 틀림(빨강)**, 학습한 인코더는 **소리 3 정답(초록)**. 내부 검증 153/320 → 320/320, 학습 6분 30초, 정답 달린 자료 2,000개.
4. **21–27초 결과**: 떼어 둔 400/400, 시험 24/24, 문제당 약 0.09초.
- 한 줄 요약: "귀가 없는 AI는 소리를 '그림'으로 바꿔 시간축을 맞춰 비교했고, 학습 6분 만에 사인파와 사람 목소리를 짝짓는 법을 배웠다."

## M4 움직여야 보이는 캡차 (m4_pov.mp4, 28초)
1. **0–5초 입력**: 점 영상이 재생되고 십자선이 훑음, 'STATIC FRAME → TEXT: NONE' — 멈춘 장면에는 글자가 없음. 범용 AI는 2/12(찍기 수준).
2. **5–13초 두 가설**: 노란 칸 '배경이 +2픽셀 움직였다', 파란 칸 '글자가 −2픽셀 움직였다'로 프레임 쌍을 비교해 쌓을수록 큰 화면에 **2E9N**이 떠오름. 대비 막대 상승.
3. **13–18초 글자 읽기**: AI 모델이 네 자리를 확률로 읽음 — 프레임 1쌍일 땐 **2S3J로 틀리다가(빨강)** 쌓이면 2E9N으로 확정.
4. **18–22초 선택지**: 6개 점수 막대, 2E9N(−0.12)만 압도적.
5. **22–28초 학습 기록**: 첫 시도(자료 500개, 회색) 글자 정답률 89%에서 정체 → 공식 코드로 자료를 5,750개로 늘린 최종(하늘색) 2에폭 만에 100%. 학습 28분, 검증 300/300.
- 한 줄 요약: "공개된 생성 코드로 연습 문제를 직접 만든 AI는, 점이 어느 쪽으로 움직였는지 계산해 글자를 찾아냈다."

## M5 ARC-AGI-3 (m5_pov.mp4, 40초)
- 전용 봇이 아니라, 설명 없는 게임을 처음 보는 AI가 공식 방식으로 직접 푼 실제 기록(행동 721개)을 공식 게임 엔진으로 다시 돌린 화면. 행동 하나를 0.03초로 압축.
1. **화면 왼쪽**: AI가 본 64×64 게임 화면. 행동마다 바뀐 칸에 노란 테두리, 클릭은 흰 조준선, 방향키는 큰 화살표.
2. **오른쪽 위**: 게임 3개(LS20 7단계, FT09 6단계, VC33 7단계) 진행 칸이 초록으로 채워짐, 다 깨면 WIN.
3. **오른쪽 가운데**: 지금 단계 행동 수와 막대. 흰 선 = 공식 사람 기준, 빨간 끝 = 상한(사람 × 5). 아래 총 행동 수·깬 단계·실제 경과 시간.
4. **단계 통과 순간**: 화면이 초록 테두리로 번쩍 + 'L3 CLEAR · AI 43 HUMAN 73' 같은 비교.
5. **오른쪽 아래 막대그래프**: 깬 단계마다 AI(하늘색) vs 사람 기준(회색)이 쌓임 — 대부분 AI가 더 짧음(노란색 = 사람보다 많이 쓴 단계, VC33 1단계 1개).
6. **마지막**: 20/20 · AI 721 행동 vs 사람 기준 1,431 · 실제 45분 41초 · 30분 시점에는 13/20(빨강).
- 게임별로 AI가 알아낸 규칙(화면엔 없음, 대본용): LS20 = 열쇠 모양·색·방향을 문 무늬와 맞춰 들어가기(흰 십자=회전, 색 칸=색 바꿈, 노란 칸=에너지), FT09 = 3×3 미니 무늬대로 칸 칠하기, VC33 = 칸막이 수조의 물을 옮겨 부표 높이 맞추기.
- 한 줄 요약: "설명 하나 없이 시작한 AI가 45분 만에 20단계를 다 깼고, 거의 모든 단계에서 사람 기준보다 적게 움직였다. 다만 사람과 같은 30분 규칙이었다면 13단계에서 멈췄다."
